# Context

Domain glossary for the es_adlershof data pipeline.

- **Scenario** — combination of target year and climate scenario, e.g.
  `2050_mean_rcp85`. Name of a file in `scenarios/` and the `SCENARIO` make
  variable. Selects which data oemof-pipe writes into a datapackage.
- **Year** — planning horizon (`2025`, `2035`, `2050`); `YEAR` make variable.
  Sets the datapackage time index start and year-only datasets (e.g. COPs).
  Independent of `SCENARIO` in the Makefile.
- **Climate** — climate scenario of the DWD test reference year (TRY):
  `mean_rcp26`, `mean_rcp45`, `mean_rcp85`, `extr{1,2,3}_rcp85`. Weather file
  periods map to years: `p1` → 2020 (wind) or 2025 (gsee), `p2` → 2035, `p3` → 2050.
- **Topology** — heat supply layout: `central`, `decentral`,
  `low_temp_central`. Part of NPRO scenario/building names; merged in demand
  profiles.
- **Dataset** — intermediate data generated by a script under `datasets/`,
  one subfolder per pipeline step.
- **Marker** — the metadata JSON a script writes last; its existence means the
  dataset is complete. Make uses it as target
  (see [ADR 0001](docs/adr/0001-make-targets-skip-existing.md)).
- **Blueprint** — base datapackage `datapackages/adlershof_{YEAR}/` built by
  `oemof-pipe blueprint`, with empty entries.
- **Datapackage** — scenario datapackage `datapackages/adlershof_{SCENARIO}/`
  built by `oemof-pipe scenario` from the blueprint and datasets.
