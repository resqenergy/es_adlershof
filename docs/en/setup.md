# Setup and execution

## Installation

The project requires Python 3.13 or newer. Dependencies are managed with [uv](https://docs.astral.sh/uv/).

```bash
uv venv .venv
uv sync
```

Two dependencies are installed directly from Git:

- **npro** — `https://github.com/resqenergy/npro`
- **oemof-pipe** — `https://github.com/rl-institut/oemof_pipe`

The sources are configured in `pyproject.toml` under `[tool.uv.sources]` and are resolved automatically by `uv sync`.

## Environment variables

The script needs access to the NPRO tool using credentials.
Additionally, the paths for datasets must be set correctly.
This can be done in a `.env` file at the project root:

```ini
NPRO_EMAIL=<user>
NPRO_PASSWORD=<password>
NPRO_PROJECT=2591-13-0

NPRO_SCENARIO_DIR=datasets/npro_scenarios
NPRO_WEATHER_DIR=raw/weather
NPRO_RESULT_DIR=datasets/npro_buildings
```

The `.env` file must **not** be checked into the Git repository (see `.gitignore`). `settings.py` loads the variables automatically via `python-dotenv`.

## Makefile pipeline

The `Makefile` is the central tool for running the data pipeline. Each target corresponds to a processing step; dependencies between targets are defined in the Makefile and run automatically.

| Target | Description | Dependencies |
|---|---|---|
| `make areas` | Merge raw areas and usage units per cluster | — |
| `make areas_forecast` | Compute area forecast for 2035 and 2050 | `areas` |
| `make npro_scenarios` | Create NPRO scenario YAML files | `areas_forecast` |
| `make npro_buildings` | Run NPRO building simulations (`npro run all`) | `npro_scenarios` |
| `make demand_profiles` | Aggregate demand profiles from NPRO results | `npro_buildings` |
| `make wasteheat_profiles` | Compute hourly waste-heat profiles | `demand_profiles` |
| `make wasteheat_cops` | Compute COP time series for waste-heat heat pumps | — |
| `make wasteheat_capacities` | Compute waste-heat capacities | — |
| `make solar_thermal` | Compute solar thermal profiles | — |
| `make parameters` | Prepare technology catalog and compute capacity costs | — |
| `make datapackage` | Build data package via oemof-pipe (blueprint + scenario) | — |
| `make all` | `wasteheat_profiles`, `wasteheat_cops`, `areas_forecast`, `parameters`, `datapackage` | — |
| `make export_datapackage` | Export finished data package to S3 | — |

### Parameters

Several targets accept Makefile variables:

- **`SCENARIO`** — scenario name (default: `2035_mean_rcp85`). Affects `wasteheat_profiles` and `datapackage`.
- **`YEAR`** — target year as a number (default: `2035`). Affects `wasteheat_profiles` and `wasteheat_cops`.

## Scenarios

An alternative scenario is generated by passing the `SCENARIO` parameter:

```bash
make datapackage SCENARIO=2050_mean_rcp85
make wasteheat_profiles SCENARIO=2050_mean_rcp85 YEAR=2050
```

Available scenarios correspond to the folder names in `datasets/npro_buildings/` and the entries in `scenarios/`.
