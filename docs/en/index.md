# Energy System Adlershof – Documentation

This project builds oemof.tabular data packages for the energy system of the Adlershof urban quarter (Berlin) as part of the ResQEnergy project. The data packages represent different climate scenarios (RCP 2.6, 4.5, 8.5) and time horizons (2035, 2050) and serve as input for energy system optimization with oemof.tabular.
